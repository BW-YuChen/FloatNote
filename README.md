# 浮笺 FloatNote

常驻桌面的极简便签工具。待办、随手笔记、每周计划，Markdown 即时渲染，支持 LaTeX 公式与 KaTeX、便签互链、日期时间地点自动高亮、到点提醒。正文以纯文本 `.md` 保存在本目录内。

**下载**：到 [Releases](../../releases/latest) 取 `FloatNote.exe`（单文件自包含，约 69 MB，双击即用，无需安装 .NET）。

## 使用

双击 `FloatNote.exe` 即可，无需安装、不写注册表。首次运行会在同目录生成 `data\`，并新建一条**每周待办**和一条使用说明。

| 操作 | 方式 |
|---|---|
| 新建便签 / 每周待办 | `Ctrl+N` 或侧栏 `＋`（`＋` 里可选类型）|
| 立即保存 | `Ctrl+S`（平时停手 0.6 秒自动保存）|
| 唤出 / 收起 | `Ctrl+Alt+N`（任意程序内生效）|
| 调整字号 | `Ctrl+滚轮` |
| 切换层级 | 标题栏「置顶 / 普通 / 贴桌面」按钮 |
| 固定置顶 | 标题栏「固定」按钮：锁定在最上层，被别的程序压下去会自动抢回 |
| 切换配色 | 标题栏右侧月亮图标：浅色 → 深色 → 跟随系统 |
| 折叠侧栏 | 标题栏 `☰` |
| 重命名便签 | 侧栏条目双击 |
| 删除便签 | 侧栏条目右侧 `×`（移入 `data\trash`，可找回）|
| 分类标记 | 点侧栏条目左侧的小图标，从预置图案 / 颜色里挑 |
| 便签置顶 | 悬停条目点 `△`，钉到列表最上方 |
| 打开设置 | 标题栏齿轮 `⚙`（开机自启、字号、配色、层级等都在这里）|

托盘图标提供：显示/隐藏、固定置顶、层级切换、配色、立即结算本周待办、开机自启、退出。关闭窗口按钮是收进托盘，退出请走托盘菜单。

## Markdown 快捷键

光标在正文里时可用，选中文字则包裹选中的部分，未选中则插入占位词并自动选中，直接打字即可覆盖。

| 快捷键 | 效果 | 源码 |
|---|---|---|
| `Ctrl+B` | **粗体** | `**文字**` |
| `Ctrl+I` | *斜体* | `*文字*` |
| `Ctrl+U` | <u>下划线</u> | `<u>文字</u>` |
| `Ctrl+Shift+X` | ~~删除线~~ | `~~文字~~` |
| `Ctrl+E` | `行内代码` | `` `文字` `` |
| `Ctrl+Shift+H` | **高亮** | `==文字==` |
| `Ctrl+Shift+K` | 链接 | `[文字](https://)` |
| `Ctrl+Shift+M` | 行内公式 | `$x$` |
| `Tab` / `Shift+Tab` | 任务升降级 | 两个空格缩进 |

高亮用的是 Markdown 的 `==文字==` 扩展语法，渲染成带黄色底色的 `<mark>`；写 `==重点==` 或按 `Ctrl+Shift+H` 都可以。代码块和行内代码里的双等号不会被误判。

## 每周待办

从侧栏 `＋` 选择「每周待办」，生成的是一张**连续清单**，不按周几切段：

```
# 每周待办

> 第 44 周 · 2026-10-26 — 11-01 · 每周一 04:00 自动结算

## 本周

- [ ] ·
```

每条空任务是 `- [ ] ·`，末尾的 `·` 只是占位符（Markdown 里没有内容的 `- [ ]` 不算任务），删掉换成自己的事就行。

**每周一 04:00 结算**（程序开着才执行，错过的话下次启动会补上）：

- 已勾选的任务直接清除
- 没做完的搬进文末的 `## 上周未完成` 区块，并以红色显示
- 想要立刻结算一次，右键托盘图标 →「立即结算本周待办」

## 二级子任务

任务下面按 `Tab` 就变成它的子任务，`Shift+Tab` 退一级：

```
- [ ] 写完高数作业
  - [ ] 第一题到第五题
  - [ ] 检查一遍
```

子任务全部勾上后，主任务会自动跟着勾上（单向，取消主任务不会反勾子任务）。

## 截止日期

正文任意位置写 `ddl{2026-11-01 23:59}`：

- 打完 `ddl` 会自动补出一对花括号，光标停在括号中间
- 显示时长这样：`ddl␣2026-11-01 23:59␣` —— 花括号不可见，整段是红色
- 代码块和行内代码里的 `ddl` 不会触发补全

源码里花括号始终保留，所以用别的编辑器打开还是 `ddl{...}` 的完整写法。

## 便签之间互链

在任何一条便签里写下**另一条便签的标题**（两个字符以上），文字旁会出现 `✓ ✗`：

- 点 `✓` → 这几个字变成蓝色超链接，点它直接跳到那条便签
- 点 `✗` → 这一次不提示

链接在 Markdown 里存成 `[标题](floatnote://note/<id>)`，用别的编辑器打开也能看出是链接。

`floatnote://` 是浮笺自己的内部协议，**不需要在系统里注册**，也不会调用浏览器或商店：所有点击都在程序内部被拦截并处理，任何漏网的跳转也会在 WebView 层被取消。所以在浮笺里点这类链接不会出现「获取打开此链接的应用」之类的系统提示。

> 如果你用记事本把这条链接复制到别处（浏览器、Word）再点，那是程序之外的环境，系统会提示找不到处理程序——这是正常的，跟浮笺无关。

## 自动高亮

正文里的关键信息会自动带底色，不同类型不同颜色：

| 类型 | 例子 |
|---|---|
| 日期（蓝） | `2026-10-26`、`10月26日`、`明天`、`周三` |
| 时间（橙） | `14:30`、`下午3点`、`9:00-11:00` |
| 地点（绿） | `@图书馆`、`3号楼`、`A301室`、`会议室` |

没有前缀的地点写不出来时，加 `@` 最稳（如 `@图书馆`）。状态栏右侧的「高亮」可以整体关掉。

这里说的是**自动识别**出来的信息底色（日期/时间/地点三类）。如果你想手动标一段重点，用上面的 `==文字==` 或 `Ctrl+Shift+H`，那是另一套黄色底色、独立于这个开关。

## 提醒

光标停在刚写完的时间/日期后面，会冒出一个 `⏰ ✓ ✗` 提示条：

1. 点 `✓` 打开提醒设置框，时间与内容已按上下文预填（`明天下午3点` 会解析成明天 15:00），可以直接改
2. 点「添加提醒」后保存到 `data\reminders.json`
3. 到点由系统托盘发 Windows 通知，点通知正文可跳回来源便签

侧栏分「便签 / 提醒」两页，提醒页列出全部待触发与已触发（划线）的提醒，按时间排序，点条目跳回来源便签，`×` 删除。

识别的时间写法：`2026-10-26`、`10月26日`、`今天/明天/后天`、`周三`、`14:30`、`下午3点`、`上午9点半`。识别不准就直接在弹出的框里改，反正每次都要确认一次。

> 通知走的是系统通知区，如果 Windows 开了「专注助手 / 勿扰」或关掉了通知，气泡会被静默，届时到点在 `data\reminders.json` 里仍会被标记为已触发。

## 设置页

标题栏的 `⚙` 打开整幅设置页，`Esc` 或左上角 `‹` 返回。共五组：

| 分区 | 可调项 |
|---|---|
| 启动 | 开机自启动（写 `HKCU\...\Run`）、启动时隐藏到托盘 |
| 窗口 | 窗口层级、固定置顶、配色、正文字号（11–22）、显示便签栏 |
| 编辑 | 日期时间地点高亮、关键词互链提示、每周一 04:00 自动结算 |
| 数据 | 显示数据目录并可一键打开、立即结算本周待办 |
| 关于 | 版本号、GitHub 仓库、退出程序 |

所有改动立即生效并写入 `data\settings.json`，不需要重启。

- **开机自启**以注册表为准：如果你在「任务管理器 → 启动」里手动禁用了它，设置页会如实显示为关闭。
- **启动时隐藏到托盘**适合配开机自启使用，开机后不弹窗，用 `Ctrl+Alt+N` 唤出。
- **每周一 04:00 自动结算**关掉后只能手动结算（设置页按钮或托盘菜单），适合不想让程序自动改写待办的人。

## 层级说明

| 档位 | 表现 |
|---|---|
| 置顶 | 压在其它窗口之上，切到别的程序也不会被盖住 |
| 普通 | 与普通窗口同层，随 `Alt+Tab` 切换 |
| 贴桌面 | 沉到所有窗口之下、浮在壁纸上，像桌面挂件；点任务栏或 `Ctrl+Alt+N` 可唤回 |

「固定」按钮开着时，窗口层级被锁在置顶，每 2 秒校验一次窗口样式位，被全屏程序或任务栏重建挤下去会自动补回。点层级按钮切到「普通 / 贴桌面」会自动解除固定。

限制：按 `Win+D` 显示桌面时，「贴桌面」档位会随其它窗口一并收起，这是系统行为。

## 数据存储

```
data\
├─ notes\<id>.md    每条便签一个 Markdown 文件，可直接用任意编辑器改
├─ index.json       便签顺序、标题、分类标记、置顶状态、当前选中项
├─ reminders.json   提醒列表（时间点、内容、是否已触发）
├─ settings.json    窗口位置尺寸、层级、固定置顶、配色、字号、开机自启
├─ trash\           删除的便签（纯文本，手工移回 notes 即可恢复）
└─ cache\           WebView2 运行时缓存，可随时删
```

备份就是复制 `data\notes` 与 `data\reminders.json`。整个文件夹拷到别的机器上照常能用。

## 从源码重新编译

需要 .NET 10 SDK。双击 `build.bat`，或在 `src\` 下执行：

```
dotnet publish -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true ^
  -p:IncludeNativeLibrariesForSelfExtract=true -o ..\publish
```

产物是单个自包含 exe（约 69 MB，内含 .NET 运行时）。

## 已知依赖与限制

1. **需要 Microsoft Edge WebView2 运行时**。Windows 11 全系自带；Windows 10 若提示缺失，装一次 Evergreen Runtime 即可（微软官网免费）。
2. exe 体积 69 MB 是自包含运行时的代价；若目标机已装 .NET 10 桌面运行时，可改为框架依赖发布，体积降到约 2 MB。
3. `Ctrl+Alt+N` 可能与其它软件冲突；冲突时状态栏会提示，改用托盘唤出。
4. 极简取向，没有富文本工具栏：所有格式靠 Markdown 语法。
5. 公式出错不会崩溃，会原样显示 LaTeX 源码。
6. 提醒依赖系统通知，被「勿扰」拦下时不会补弹窗。
7. 「每周待办」建好后的周次日期是静态文本，跨周后需要自己改标题里的日期（或新建一条）。

## 实现说明

- 外壳：.NET 10 + WPF，无边框窗口，原生圆角，层级切换走 Win32 `SetWindowPos`，固定置顶读 `WS_EX_TOPMOST` 样式位校验
- 正文：内嵌 WebView2，编辑器内核 Vditor 4.0.1（IR 即时渲染）+ KaTeX + highlight.js，全部资源本地化，运行时不联网
- 自动高亮用 CSS Custom Highlight API（`::highlight()`），不改 DOM，不打断光标与输入法
- 提醒调度在宿主侧用 15 秒粒度的 `DispatcherTimer`，通知走 `NotifyIcon` 气泡（Win10/11 归入通知中心）
- `src\tools\` 内为开发期自测脚本（无侵入验收、截图、图标生成），非运行时必需
